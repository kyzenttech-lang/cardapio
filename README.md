# Cardápio online · demonstração

Demonstração visual de cardápio online para pizzarias, feita pela KYZENT.
Não é um sistema: sem servidor, sem banco, sem login e sem pagamento.
O nome "Pizzaria Exemplo", os itens, os preços e as imagens são de exemplo.

Site: https://kyzenttech-lang.github.io/cardapio/

## Como abrir

Abra `index.html` no navegador. Não precisa instalar nada nem rodar build.

## Onde trocar o número do WhatsApp

No começo de `js/app.js`, na constante `WHATSAPP_NUMERO`, no formato
`55DDDNUMERO` (hoje `5519000000000`, número de teste).

## Onde mudar o cardápio

`js/data.js` (categorias, itens, preços, sugestões). Créditos das fotos e da
fonte em `assets/CREDITOS.md`.

KYZENT: https://kyzenttech-lang.github.io/site/
